Key analysis parity

Dev-only (v15.1). Decodes each reference track on this browser's production path (an OfflineAudioContext at 22050 Hz, then analyseKeyOf) and compares it with the reference analyser's stored chroma, A4, key and confidence (build spec §11.3). Parameters: lib (library.json URL), src (audio base URL), ext (wav or mp3), bounds (tolerant or mp3), optional list (a JSON array of sources) and env (compare envelopes on every Nth track). Rows are by library index.
